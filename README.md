# iPad 9 柿子姿态识别

这是不需要 Mac 的 PWA 版本。Safari 调用 iPad 后置摄像头，ONNX Runtime Web 在 iPad 本机完成推理，不上传相机画面。

## 使用条件

- iPadOS 16 或更高版本，建议升级到该设备支持的最新版本。
- 页面必须部署在 HTTPS 地址；直接打开文件或用局域网 HTTP 地址无法取得 iPad 摄像头权限。
- 第一次打开需加载约 10.5 MB 模型。成功加载并加入主屏幕后，应用资源会被缓存。

## 部署

把本目录原样上传到任意静态 HTTPS 网站（GitHub Pages、Cloudflare Pages、Netlify 等）。不要更改 `best.onnx` 的文件名。

在 iPad Safari 打开网址，点击“共享”→“添加到主屏幕”，以后从桌面图标启动。

## 识别规则

- 默认仅显示置信度不低于 0.65 的柿子。
- 绿色点是柿蒂，蓝色点是柿尖，黄色箭头从柿蒂指向柿尖。
- 当任一关键点置信度低于 0.50 时不画方向，避免柿蒂遮挡或不可见时给出错误箭头。
- 这是单摄像头二维方向；无法得到原双摄标定所产生的毫米级三维方向。
